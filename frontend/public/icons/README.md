# Icônes PWA

Ce dossier doit contenir les icônes PNG référencées dans `public/manifest.webmanifest` :

- `icon-192.png` (192x192, purpose `any maskable`)
- `icon-512.png` (512x512, purpose `any maskable`)

À fournir lors de la finalisation du branding ICY. Tant que ces fichiers sont
absents, l'installation PWA reste possible mais l'icône d'application sera
celle par défaut du navigateur.

Suggestions de génération :

- https://maskable.app/ pour ajuster le « safe zone » des icônes maskables.
- `pwa-asset-generator` pour générer la collection complète depuis un SVG source.

Pas de logo binaire dans le repo tant qu'il n'est pas validé par l'équipe design.
